# ♠ VELVET Hold’em

> 애들이랑 걍 간단하게 즐기는 용도 , 온라인 홀덤

친구와 온라인으로 즐기는 **가상 칩 전용 텍사스 홀덤 웹게임**입니다.
현금 충전·환전 기능은 없습니다.

## 기능

- 닉네임으로 방 생성·참가. 최대 6명 멀티플레이
- 초대 링크와 선택형 방 비밀번호
- AI 상대 1~5명과 초급·중급·고급 난이도
- 카드 분배 → 베팅 → 플랍·턴·리버 → 쇼다운 → 다음 핸드
- 서버 족보 판정·최소 레이즈 검증·사이드 팟·동점 분배
- 개인 카드 비공개와 참가 토큰을 통한 재접속
- 채팅·빠른 채팅·게임 기록·차례 강조·30초 제한·선택형 알림음
- 모바일 반응형 스타일

시작 칩 1,000 / 스몰 블라인드 10 / 빅 블라인드 20

## 로컬 실행

**Node.js 24 이상**이 필요합니다. 외부 npm 패키지는 사용하지 않습니다.

```bash
npm run dev
```

브라우저에서 **http://localhost:3000**으로 접속합니다.
종료하려면 터미널에서 Ctrl+C를 누르세요.

같은 네트워크의 다른 기기에서는 개발 PC의 로컬 IP 주소와 포트 3000을 사용합니다.
localhost는 다른 기기에서 개발 PC를 가리키지 않습니다.
이 서버는 로컬 개발용입니다.

로컬 방 데이터는 운영체제 임시 폴더의 `velvet-holdem-local.sqlite`에 저장됩니다.
기존 서비스의 게임방·채팅·사용자 토큰은 포함하지 않습니다.

## 테스트

```bash
npm test
npm run validate
```

13개 테스트 그룹을 포함합니다. 무작위 1,000핸드의 칩 보존과 족보·헤즈업 순서·짧은 올인·최소 레이즈·사이드 팟·동점 분배·카드 비공개·동시 행동·채팅·재접속·솔로 완료를 검사합니다.

이전 공개 배포에서는 독립 참가 토큰을 가진 두 브라우저 탭으로 입장·채팅·올인·쇼다운·칩 지급을 확인했습니다.
실제 휴대폰과 서로 다른 두 물리 기기는 아직 검증하지 않았습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `page.html` | 화면·스타일·브라우저 코드 |
| `engine.mjs` | 게임 규칙·족보·팟·AI |
| `server.mjs` | 방·인증·동기화·채팅 API |
| `worker/index.js` | 합쳐진 배포용 Worker |
| `scripts/assemble.mjs` | Worker 생성 |
| `scripts/dev.mjs` | 로컬 Node.js 서버 |
| `scripts/db.mjs` | 로컬 SQLite 어댑터 |
| `drizzle/0000_rooms.sql` | 테이블 생성 SQL |
| `test.mjs` | 엔진·서버 테스트 |

수정 후 `npm run build`를 실행하세요. `worker/index.js`는 자동 생성 파일입니다.

## 인터넷 배포

**GitHub에 소스를 올리는 것과 게임 서버 배포는 별도입니다.**
서버와 데이터베이스가 필요하므로 GitHub Pages만으로 멀티플레이를 실행할 수 없습니다.

Cloudflare Workers + D1용으로 작성되어 있습니다.

1. `npm run build`를 실행합니다.
2. 자신의 Cloudflare 계정에 D1 데이터베이스를 생성합니다.
3. `drizzle/0000_rooms.sql`을 해당 DB에 최초 한 번 적용합니다.
4. Worker의 D1 바인딩 이름을 **DB**로 지정합니다.
5. `worker/index.js`를 Worker ES module로 배포합니다.
6. 배포된 HTTPS 주소로 접속해 방을 만들고 초대 링크를 공유합니다.

호스팅 계정·데이터베이스 ID·인증 토큰은 포함하지 않습니다.
복제한 사용자는 자신의 호스팅 환경을 설정해야 합니다.

## 현재 제한

- WebSocket 대신 약 850ms 간격의 상태 조회를 사용합니다.
- AI와 시간초과는 서버 요청이 도착할 때 처리됩니다. 모두 오프라인이면 재접속 후 이어집니다.
- AI는 공개 정보 기반 휴리스틱이며 포커 솔버가 아닙니다.
- 방장 자동 승계와 자리 추방은 없습니다. 다음 핸드 시작에는 방장 접속이 필요합니다.
- 참가 토큰을 잃으면 기존 자리 복구는 불가능합니다.
- 채팅은 방당 5,000개까지 보관합니다. 방 자동 삭제 기능은 없습니다.
- 새 플레이어는 핸드 사이에 입장합니다. 칩이 소진되면 핸드 사이에 가상 칩을 다시 받을 수 있습니다.
- 대규모 동시접속 테스트와 외부 보안 감사는 수행하지 않았습니다.

공유 소스에는 마지막 모바일 배치 보정이 포함됩니다.
기존 사이트의 보정본 배포는 호스팅 오류로 완료되지 않아 기존 공개 버전과 배치가 일부 다를 수 있습니다.
